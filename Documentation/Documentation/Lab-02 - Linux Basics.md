# Lab 02 - Linux Basics

## Objective

Learn basic Linux navigation and identification commands using the command line.

## Environment

* Ubuntu Linux
* VirtualBox
* User Account: santicyber

---

## Tasks Performed

### 1. Identified Hostname

Command:

```bash
hostname
```

Purpose:

Display the system hostname.

---

### 2. Identified Current User

Command:

```bash
whoami
```

Purpose:

Display the currently logged-in user.

Result:

```text
santicyber
```

---

### 3. Displayed Current Directory

Command:

```bash
pwd
```

Purpose:

Display the current working directory.

Result:

```text
/home/santicyber
```

---

### 4. Listed Directory Contents

Command:

```bash
ls
```

Purpose:

View files and folders in the current directory.

Observed directories:

* Desktop
* Documents
* Downloads
* Music
* Pictures
* Public
* Templates
* Videos

---

### 5. Navigated to Home Directory

Command:

```bash
cd ~
```

Purpose:

Return to the user's home directory from any location.

Verified with:

```bash
pwd
```

Result:

```text
/home/santicyber
```

---

### 6. Created a Directory

Command:

```bash
mkdir TestFolder
```

Purpose:

Create a new directory.

Verified with:

```bash
ls
```

Result:

```text
TestFolder
```

---

## Skills Learned

* Linux terminal navigation
* User identification
* Host identification
* Directory listing
* Home directory navigation
* Directory creation
* Understanding Linux file paths

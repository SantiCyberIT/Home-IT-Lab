# Lab 01 - Home Lab Foundation

## Objective

Build a virtual machine environment to support future IT, networking, and cybersecurity labs.

## Tools Used

- VirtualBox
- Ubuntu Desktop LTS

## Steps Performed

1. Installed VirtualBox
2. Downloaded Ubuntu Desktop ISO
3. Created Ubuntu virtual machine
4. Allocated resources
5. Installed Ubuntu
6. Verified successful boot

## Results

Successfully deployed an Ubuntu virtual machine.

## Skills Learned

- Virtualization fundamentals
- VM creation
- Resource allocation
- ISO installation
- Operating system deployment
